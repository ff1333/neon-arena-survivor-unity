## 独立程序和浏览器

`native/` 含 960×540、1280×720 与 1600×720 画面。包括中英文设置、金色六选二、两种首领、胜利、宽屏奖励；`results.txt` 保存通过标记。

首领截图通过 `-neonSmoke` 的受控装配与主动扣血准备界面，不是玩家实际两秒集齐六武器或四秒通关。截图机制不会在正常启动时启用。截图工具在测试后恢复语言和最高纪录，避免受控测试继续写入正式记录。

`web/` 为 Microsoft Edge + Playwright 操作记录：进入设置、切英文、改变总音量、静音、关闭并重开设置、切回中文、开局选武器、移动和暂停。结果 JSON 中的错误列表为浏览器异常采样；图片还进行了视觉检查，不把“脚本点完了”直接当作所有业务断言通过。语言与声音的语义断言在 PlayMode 测试中。

设置原先半透明会透出主菜单文字，现改为实底。金色面板也取消透字；滑块手柄高度与卡片点击区域固定。中文词条使用授权 Noto 字体。

## 构建与附件

三平台 BuildReport 分别见 `Windows-build-summary.txt`、`WebGL-build-summary.txt`、`Android-build-summary.txt`，以最终报告为准；包哈希见 `SHA256SUMS.txt`。

Windows/WebGL 各有 1 项构建告警，最终 Android 为 3 项，三平台均为 0 错误。最终 Android 的告警涉及原有 `MobileJoystickTouchArea.mouseActive` 未使用字段、Performance Test 工具刷新运行信息资源，以及诊断信息缺少完整符号。较早失败尝试还出现过 SDK 仓库清单联网提示。完整构建日志留在本地验证工程 Builds 中，不将可能包含环境变量的失败日志推到公开仓库。

独立程序仍记录地板 Sprite Tiling 导入提示；检查画面可显示地板，但未把这一点称为“运行日志零警告”。这次保留用户已有贴图导入设置。

最后一轮 Android 曾因两个 Unity 构建共享 Gradle daemon，被另一个构建退出时的停止命令打断。改为单独运行后重建；不使用旧 APK 冒充成功产物。构建多个项目时按顺序执行安卓步骤。
