# Neon Arena Rebuild v1.3.0

发布日期：2026-10-05。

## 主要更新

- 集齐六把武器后触发小首领；击败后直接提升两级，并从六项金色强化中选择两项。
- 完成两项选择后进入最终首领战；加入攻击预警、弹幕、范围攻击、冲刺、半血强化和胜利结算。
- 默认简体中文，支持英文切换、静音、总音量、音乐和音效音量，本地保存。
- 保留此前的六武器槽、数据驱动配置、对象池、差异化敌人与经验物、战斗反馈及 Android 浮动摇杆。
