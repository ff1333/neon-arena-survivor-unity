## 口播稿

这是我使用 Unity 6 和 C# 独立重写的 2D 生存射击项目。玩家通过移动躲避敌人，武器会在各自射程内独立选择目标并自动射击，击败敌人后拾取经验，通过三选一升级形成最多六个武器槽位的组合。

工程上，我用 ScriptableObject 管理三种武器、三类敌人和升级数据，用注册表完成射程内目标筛选，并通过对象池复用子弹、敌人、经验物和出生预警。项目完成了十分钟发布候选测试，以及 Windows、WebGL 和 Android 构建；Android 版本还实现了基于 Input System 的全屏浮动摇杆。源码、开发日志、Profiler 记录和正式构建都放在 GitHub。

## 录制要求

1. 使用最终 `main` 对应的正式包，不用参考工程或临时测试数值。
2. 游戏片段必须真实操作，不能用静态图片冒充运行。
3. Profiler 画面只说“完成对象池实现和代表帧记录”，不说未经证据支持的提升百分比。
4. 录制前关闭聊天、通知和包含隐私信息的窗口。
5. 导出为 1080p、H.264、MP4；完整播放一遍后再上传。
6. 不愿录口播时可以只用表格中的短字幕，但成片仍要保留真实游戏声音或稳定的低音量背景音。
