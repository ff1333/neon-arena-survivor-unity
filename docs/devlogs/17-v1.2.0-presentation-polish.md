# v1.2.0：美术与战斗反馈三轮迭代

日期：2026-10-03 至 2026-10-04。实现/自动验证：Codex 辅助；新版手动真机：待确认。

## 第一轮：替换占位画面

为玩家、Chaser、Dasher、Berserker 制作不同轮廓的栅格精灵：无人机、带角追踪者、尖锐冲锋者和厚甲狂暴者。
保留原先类型颜色、狂暴变色和受击恢复逻辑。三类武器加入可区分轮廓的图标，子弹仍保留原武器色。
增加竞技场金属地板贴图、子弹拖尾、枪口粒子、命中数字和受伤边缘提示。
贴图由 `tools/generate_polish_art.py` 可复现生成，无外部素材下载或付费依赖。

## 第二轮：截图审查后的修复

- 发现统一按钮状态色后部分原始白色 Image 出现白底白字，改为明确背景色和独立高亮乘色。
- 开始页去掉原来小型绿色模态框，改用场景背景和左侧标题/开始操作；暂停保留清晰的恢复与重开动作。
- 小窗口武器页发现重复“Choose an upgrade”旧标题，隐藏旧标题，保留当前“CHOOSE STARTING WEAPON / 升级标题”。
- 检查三个敌人能用轮廓区分；伤害数字限制 24 个轮换复用，命中/死亡颜色不同。
- 子弹回池关闭并清除拖尾，发射时先 Clear 再启用，防止新出生点与旧位置连成线。

## 第三轮：边界与构建

发布边界脚本检查六槽装备限制、开局三种武器、池扩容与重复回收、经验形态及 UI 绑定。
独立 Windows Player 自动执行开始→选武器→战斗，检查三种精灵与已回池拖尾清空，捕获开始/选武器/战斗/暂停/小窗口截图。
自动展示时主动摆放三种敌人，以便检查外观；不代表正式游戏第一秒就会出现全部类型。
最终构建和浏览器证据在 `docs/test-results/v1.2.0/`；编辑器边界报告见 `18-v1.2.0-build-verification.md`。
新版安卓真机、长时间平衡和不同手机性能未由自动截图代替，不能沿用 v1.1.0 真机结论。

## 代码学习

`ArenaPresentation` 在 Main 加载后设置外观，不改变碰撞和升级数值。
`PolishArtImporter` 配置 PNG 为 Sprite；`WeaponDefinition.Icon` 读取新版图标，保留原资源回退。
`CombatFeedback` 复用数字和粒子；`Projectile` 管理拖尾生命周期。
这轮没有改变刷怪压力、武器伤害、六槽上限、敌人接触伤害或升级配置。
